The course runs in nine modules. The core path (modules 0 to 5) builds one idea on the next. Each case study names the
module it builds on, so you can start it as soon as you finish that module instead of waiting until the end. Lessons
you finish show a check mark. The beginner route is an order. Open the next case only after the Best after module on
its card.
