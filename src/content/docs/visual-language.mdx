Every diagram in this course draws each kind of component the same way. A database is always a teal cylinder, and a load
balancer is always a yellow hexagon. Once you learn the shapes, you can read any diagram at a glance.

Color is never the only cue. Each component also has its own **shape**, **icon**, and **label**, so the diagrams work in
grayscale, in high contrast mode, and for people with color vision deficiency.

## Arrows and traffic

- A **solid arrow** shows a request path.
- A **dashed arrow** shows background work, such as a database copying data to a replica.
- A **moving dot** on an arrow is one request in flight. When your device asks for reduced motion, the dots stay hidden and
  the tables beside each simulation carry the same information.
- A **ring** around one component marks the focus of the current step. Other components in the step keep a heavier outline, and everything else fades back.
