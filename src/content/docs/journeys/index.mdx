A learning path builds prerequisite concepts in sequence and ends with a case study that applies them to a system.
Start at stage 1, or open the case study directly if you already know the concepts.
Mastered concepts count across paths. No previous system design knowledge is required.

<SystemJourneys />

Search covers news indexing, query serving and freshness. A full web crawler is outside its scope.
Distributed storage covers partitions, replicas, quorums and repair. Chat and feeds explore ordering, retries and fan-out.

For longer lessons, use the [full course map](../curriculum/). Revisit missed ideas in the [review queue](../review/).
